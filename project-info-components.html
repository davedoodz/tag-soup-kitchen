Project info — modular panel components

Building on your Paper split stage: the right 510px panel becomes a stack of drop-in modules. Below is (1) a full composed panel showing them assembled, and (2) a component library — each block rendered at true panel content width (446px), labelled with when to use it. Everything uses the deployed tokens only: Manrope + IBM Plex Mono meta, #111 / #8A8A8A / #E6E6E6 / #F2F2F2, accent #2F6BFF, r12 / r10 / r999. Mix, reorder, or omit blocks per project.
