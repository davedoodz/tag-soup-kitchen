3Anatomy

Every path lives on a 24-unit box with a 2-unit keyline it never crosses, and every straight edge sits on a half-unit so a 1px stroke lands on a device pixel. That is the same reason the nav hamburger reads crisp at 1px.

Grid
24 × 24 units, 10px per unit shown here
Keyline
2 units of padding on every side — 20-unit live area
Stroke
1.5px, uniform, no tapering
Terminals
round cap, round join
Alignment
horizontals and verticals on .5 offsets, diagonals at 45°
Colour
currentColor only — #1a1a1a on paper, #ffffff on ink, never a hue
Corners
0px on geometry; container radii stay 8 / 12 / 16px
Elevation
none — no shadow, no blur, no gradient fill

5Verdict

Adopting any of this is an amendment to the system, so it should be the smallest amendment that does the job.

Keeps the system

  • currentColor only — the set inherits #1a1a1a, #666666, or #ffffff and adds no hue.
  • No shadows, no gradients, no filled plates other than the existing badge circle.
  • Container radii reuse the sanctioned 8 / 12 / 16px; icon geometry has none.
  • Optical stroke keeps every mark at one weight, the drawn equivalent of weight 400.
  • The framed direction is literally the nav hamburger container, reused.

Costs the system

  • Any adoption contradicts “no iconography beyond the hamburger glyph”.
  • Graphic at 2.5px competes with 40px headings — it reads as a second bold weight.
  • Hairline at 1px disappears on ink; it needs 1.25px minimum on dark surfaces.
  • Badge borrows the numbered-chapter circle and dilutes the serial motif.
  • Sixteen marks is a set to maintain; the page currently needs five.

Recommendation: adopt Editorial at 24px / 1.5px for inline use and Framed for the nav, drop Badge entirely so the numbered circle stays unique, and ship only the marks a screen actually uses — arrow-up-right, chevron-right, menu, close, filter.
