Archived 18.08.26. Five ways the portfolio could behave, reviewed in one sitting: the contact sheet grid and the split browser were accepted, the other three were not.

Kept as a record of the round rather than as live work. Every direction still runs, still shows the same twelve placeholder projects, and still writes verdicts to feedback/reviews.json while “npm run sites” is running.

1Directions

  • 01 Contact sheet grid Dense uniform grid, live filters, inline overlay. Optimises for scanning a large body of work fast. 4192
  • 02 Editorial scroll One project per screen, oversized type, scroll-snap. Optimises for narrative and impact over speed. 4193
  • 03 Split browser Persistent list beside a preview pane. Optimises for comparison and repeat visits. 4194
  • 04 Fullscreen reel One project owns the screen, arrow or swipe to advance. Optimises for presenting live. 4195
  • 05 Command index Keyboard-first searchable index with a command palette. Optimises for depth and recall. 4196
  • 06 UX flows — wireframes Four low-fidelity flows behind these directions, with a device toggle. 4197
