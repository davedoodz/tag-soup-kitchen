AColorBright says photography is the only thing allowed to interrupt the white page — but there is no approved photography yet, so every image slot in the portfolio is currently empty. These five shaders are the stand-in: generative achromatic plates that fill an image slot with material instead of a placeholder grey.

One uniform contract, five coverage fields, two palette values per plate. Nothing here renders a hue, a shadow, or a smooth gradient — coverage is posterised into the system’s own greys and dithered on an 8×8 ordered matrix, so a plate reads as printed ink, not as CSS.

Archived 18.08.26 — this round is closed. All five plates were accepted, and the live version is no longer here: it ships as the Shaders section of the portfolio itself, where the uniforms are drivable and every frame exports as a PNG. Locally that section runs on port 4178.

3The contract

A field is a single function — float coverage(vec2 uv, vec2 px) returning ink coverage from 0 to 1. Everything after that is shared: contrast, grain, posterising, dithering, and the two-colour mix. Adding a sixth plate means writing one function, not one program.

u_res
drawing-buffer size in device pixels; uv is aspect-corrected on y
u_dpr
device pixel ratio — px is CSS pixels so cell sizes stay design-space
u_time
seconds since load, already multiplied by speed; 0 freezes the plate
u_scale
field frequency, or halftone cell and column width in CSS pixels
u_contrast
gamma on coverage, 2.2 → 0.45; thins or thickens lines without crushing them
u_grain
device-pixel noise added to coverage, resampled 20 times per second
u_steps
posterise levels, 2–12; below 2 the field stays continuous
u_dither
1 blends the steps on the 8×8 ordered matrix, 0 leaves hard separations
u_seed
hash offset — the only difference between two plates of the same field
u_ink / u_paper
the two palette values coverage mixes between; both come from the token set

5Verdict

Generative plates are an amendment to the system, so the question is whether they earn the image slot they occupy — or whether an empty white slot was the more honest answer.

Keeps the system

  • Two token values per plate — 0% colourfulness holds, no hue is ever mixed.
  • No shadow, no blur, no elevation: coverage and radius do all the work.
  • Posterising into 4–8 greys stops a plate reading as a 2019-era gradient.
  • Halftone and sweep are sized in CSS pixels off the 8px spacing unit.
  • 12px radius, no border, no caption chrome — identical to an image slot.

Costs the system

  • “Imagery is the only chromatic interruption” — a plate is imagery that proves nothing.
  • Motion is new vocabulary: the system has no animation rules to fall back on.
  • Nine live contexts is real GPU cost on a page whose budget was type and whitespace.
  • Continuous fields at posterise off read as gradients, which the system bans.
  • Every plate is one more thing to maintain once the real photography lands.

Outcome: all five plates were accepted — Grain, Halftone, Contour, Warp, and Sweep. None was dropped and none was retired. They now ship as the Shaders section of the portfolio, where the uniform contract is exposed as an interactive lab: a visitor picks a plate, moves the uniforms, and exports the frame as a PNG. The costs listed above stand as the record of what the amendment charges the system; the decision was that the material is worth it. This round is closed and this page is kept only as its artefact.
