AColorBright is one typeface at one weight on white paper — hierarchy comes from size, tracking, and the space you leave empty.

This is the working reference for the portfolio surfaces: eight neutrals, six type sizes, one 8px spacing unit, three radii, and ten components. Nothing here has a hue, a shadow, or a font weight above 400. Photography is the only color the system accepts.

1Ink and paper

Eight neutrals, zero hues. Read the ramp as two families: text tones from ink to ash, and surfaces from paper to charcoal. Text never uses pure black; badges and icon fills always do.

Tracking is the fingerprint

Every element carries −0.01em, applied once with a universal selector. Without it the type reads as a default UI font; with it, as a set page.

3Space, shape, and grid

One 8px unit, five steps. Chapters are separated by 64px of nothing — the system has no section dividers, so vertical space is the only structure between them.

  • 8px Field-to-button gap, badge inset
  • 16px Element gap, list row padding, masonry gutter
  • 24px Nav block padding, heading-to-copy
  • 32px Page edge padding, grid gutters, copy-to-grid
  • 64px Chapter separation, footer offset

5Rules and tokens

The constraints are the system. Most review notes on these surfaces trace back to one of the lines below.

Do

  • Keep every weight at 400 and let size carry hierarchy.
  • Apply −0.01em tracking at every size, without exception.
  • Open each chapter with the numbered black badge.
  • Use 12px radius on imagery and 8px on controls.
  • Leave 64px between chapters and 256px above the hero.
  • Let photography be the only saturated thing on the page.

Don't

  • Add an accent hue, gradient, or tinted UI chrome.
  • Reach for a shadow, blur, or any raised surface.
  • Use font weight 600 or 700 to fix weak hierarchy.
  • Wrap body copy in a bordered or filled card.
  • Invent a font size outside 12, 16, 18, 24, 40, 64.
  • Fill panels with mist — banding lists is its only job.
  • Add icons beyond the hamburger glyph.
  • Set readable text in pure black.
