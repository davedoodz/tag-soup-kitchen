SYSTEM: PHOSPHOR — ROUND 01 — 9 SPECIMENS + 1 LATCH

Every surface below is a real switch: hover (or focus) probes it, click latches it. The art layer is one text node per specimen, repainted from a field function — the glyph ramp  .:-=+*#%@  carries brightness, colour carries state only: idle → probe → latched.

01

Charge field

pointer-distance falloff → 10-step ramp

The cheapest honest hover: cell brightness is 1 − distance to the cursor. Latched, a standing pulse keeps breathing out of the last probe point.

02

Decode buffer

per-cell settle threshold · glyph scramble → target text

Scramble-on-hover taken from one word to a whole plate. Every cell owns a random settle threshold; hover raises the waterline, so the text resolves as noise instead of a wipe. Leaving re-scrambles; latching holds the plaintext.

03

Dither sweep

4×4 Bayer matrix · threshold follows the knob

A switch knob with no knob. An ordered Bayer threshold turns the eased 0→1 travel into a grain front that crosses the plate; hover pre-lights the front so the control telegraphs its own direction.

04

Scanner reveal

CSS mask + registered @property · zero JS paint

Two stacked ASCII layers; the top one is masked by a radial-gradient with interpolated stops (@property), so the aperture eases open without a rAF loop. Latching opens the mask to the full plate — the reveal becomes the state.

05

Cell culture

Conway B3/S23 · hover injects soup · decay trails

Hover seeds live cells under the cursor — you are drawing the initial condition. Off holds the culture frozen and lets the trails fade; latched, the automaton runs at 8 Hz and eats whatever you drew.

06

Interference

two-source sine field · source B tracks the pointer

The pointer is the second emitter, so moiré bands bend around it — the motion reads as caused, not decorative. Latching doubles the frequency and inverts the ramp.

07

Column rain

per-column head + exponential tail · local pointer boost

The cliché, made responsive: columns near the cursor accelerate, the rest drift. Off, the fall stalls to a residue; latched, it runs. Direct manipulation of a background effect.

08

Bracket lock

box-drawing frame · steps() typewriter · pure CSS

No canvas, no rAF, no JS: corner brackets push out on individual transform properties (identity set on the base so the stacking context never shifts), and the status line types with steps(). Latched, the line stays written.

09

Rule engine

elementary CA · rule 90 ⇄ 110 · seed follows the pointer

Each row is one generation. Hovering moves the single live seed cell, so the Sierpiński cone tracks the cursor; latching swaps rule 90 for rule 110 and starts scrolling generations upward. The toggle changes the mathematics, not the styling.

Round notes

What carried

  • 02 Decode buffer and 00 Power latch — the two where the hover state is legible as information rather than as polish. Both survive being scaled down to a nav item.
  • 06 Interference — best cause-and-effect: the pointer is an emitter, not a spotlight.
  • 04 Scanner reveal — cheapest per frame (no JS paint at all) for the strongest impression.

What to drop

  • 07 Column rain reads as reference, not as a control. Keep only if a page needs one atmosphere block.
  • 05 Cell culture is beautiful and illegible — the state is impossible to read at a glance, which disqualifies it as a switch.

Technique ledger

  • One requestAnimationFrame loop, ~30 fps, iterating only specimens that are on screen and in motion; it stops itself when the page is quiet.
  • One text node per plate — no per-cell spans, so a repaint is a single string assignment.
  • Grids are measured, not assumed: a DOM probe reports the character advance, the column count follows the plate width (here 60×12 per plate, 179×17 for the latch) and a ResizeObserver rebuilds the field — letters re-derive their own scale from the cell aspect. Integrity relies on ASCII-only ramps and font-variant-ligatures:none.
  • Reduced motion: the loop never starts, each specimen renders one static frame per state, and the typewriter resolves instantly.
  • Every plate is a <button role="switch"> with aria-checked; art layers are aria-hidden, and focus drives the same probe as hover.
