Below the gallery + footer — 5 UX explorations

New system, HAIRLINE, reverse-engineered from two objects only: the signature card and the AAA frame. Nothing from the previous token set is used — no accent colour, no 56px display scale, no widget radius. Both sources are entirely achromatic and divide space with 1px rules, so those became the system's two hard laws. AAA's footer is an empty 671px slot, so each variant proposes a footer as well as the below-gallery zone.
